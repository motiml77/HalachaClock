## הטבלאות — האתר החיצוני מול מה שהאפליקציה מציגה

עמודת **״באפליקציה״ אינה פלט המנוע.** היא נלקחה מהמסלול שהמשתמש רואה בפועל:
`relevantTimedZmanim(date)` → `instantOf(kind)` → `asZmanTime`. זו הסיבה
שהרשימה כאן היא בדיוק השורות שהמסך מציג, בסדר שהוא מציג אותן — ולא רשימת כל
מה שהמנוע יודע לחשב.

עמודת **Hebcal** היא הערך המדויק שהוא מחזיר (`sec=1`, ברזולוציית שניות),
לא מעוגל.

- **✓** — האתר והאפליקציה מציגים את אותה דקה.
- **≈** — אותו רגע, פחות מדקה הפרש; ההבדל במחרוזת הוא רק חיתוך השניות שלנו.
- **▲** — הבדל **שיטה** מכוון. Hebcal פשוט לא מחשב את אותה הגדרה.

| התוצאה | נקודות |
|---|---|
| ✓ זהה לדקה | **217** |
| ≈ אותו רגע (הפרש מקסימלי **33 שניות**) | **17** |
| ▲ הבדל שיטה מכוון ומתועד | **165** |
| ✗ בלתי מוסבר | **0** |
| **סה״כ** | **399** |
