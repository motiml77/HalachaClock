# פלג המנחה — האתרים החיצוניים מול מה שהאפליקציה מציגה

שתי שיטות, כל אחת מאומתת מול הרשות שלה. הפער ביניהן הוא בדיוק 13.5 הדקות
הזמניות של צאת הכוכבים — ולכן הוא גדל בקיץ ומצטמצם בחורף. זו חתימה של מחלוקת,
לא של באג.

- **פלג הלוח** = צאת הכוכבים (13.5 ד״ז) פחות 1¼ שעות זמניות — הרב יצחק יוסף / לוח אור החיים.
- **פלג גר״א** = שקיעה פחות 1¼ שעות זמניות — מה שאתר ישיבה מפרסם.

## מה בדיוק מושווה כאן

עמודת **״באפליקציה״ אינה פלט המנוע**. היא נלקחה מהמסלול שהמשתמש רואה בפועל:
`relevantTimedZmanim(date)` → `instantOf(kind)` → `asZmanTime`. ערך יכול להיות
נכון במנוע ובכל זאת לא להגיע למסך, או להגיע כשורה אחרת — ולכן זו ההשוואה
היחידה שבאמת עונה על השאלה ״האם מה שרואים תואם״.

| העמודה | המקור שלה | מה היא |
|---|---|---|
| הלוח — מפורסם | `docs/luach_ohr_hachaim_reference.csv` | הערך של לוח אור החיים עצמו, בדיוק של שניות |
| גר״א — Hebcal | Hebcal API (`plagHaMincha`) | מימוש עצמאי לגמרי של חשבון הגר״א |
| אתר ישיבה | צילום המסך שנשלח | ירושלים, כ״ג באוגוסט 2026 |
| באפליקציה | `MaranZmanimEngine` דרך מסלול ה־UI המלא | המחרוזת שמופיעה על המסך |

- **✓** — זהה לדקה.
- **✓\*** — Hebcal מאוחר בדיוק בדקה אחת, ובכל 32 המקרים השניות שלנו הן ‎30–59.
  זהו **הבדל בעיגול, לא במספר**: אנחנו חותכים שניות והם מעגלים כלפי מעלה.
  לדוגמה ירושלים ה׳ בטבת (15.12.2026) — אצלנו 15:33:51, כלומר 15:33 אצלנו ו־15:34 אצלם.
  אין ולו נקודה אחת שבה הפער אינו מוסבר כך.
- החיתוך (ולא העיגול) הוא החלטה מכוונת, **אבל הנימוק שלה אינו תקף לפלג**.
  לזמני *סוף* (ק״ש, תפילה) חיתוך תמיד בטוח — הוא מקדים, ולכן אינו מאחר את
  המשתמש אחרי סוף הזמן. פלג המנחה הוא זמן *התחלה*: ממנו והלאה מותר ערבית
  ומותרת קבלת שבת. חיתוך של עד 59 שניות מציג אותו **מוקדם מדי**, וזה הכיוון
  הלא־בטוח כאן. הלוח עצמו מסמן את שורות הפלג `data-round="later"`, כלומר
  מעגל אותן כלפי מעלה. ראה ״שאלה פתוחה״ בסוף המסמך.

**אין אף תא אחד שבו האפליקציה מציגה זמן שאינו תואם למקור החיצוני שלו.**

## אימות עצמאי — ניסיון להפריך, לא לאשר

הטבלאות שלמעלה נבדקו שוב על ידי ארבעה בוחנים בלתי תלויים שקיבלו הוראה מפורשת
**להפריך** את הטענה שאין כאן טעות, ולא לאשר אותה. כל טענה שהם העלו נשלחה
לשלושה בוחנים נוספים. תשע טענות נפלו בביקורת הצולבת; אחת שרדה, והיא תוקנה
(שלוש כותרות תאריך עברי שגויות — ראה למטה).

### מה שהתגלה ומחזק את החישוב

**מצאנו את המנוע של הלוח עצמו.** royzmanim.com פתוח בגיטהאב
(`Zemaneh-Yosef/royzmanimwebsite`, הקובץ `assets/js/ROYZmanim.js`). הפונקציה
`getPlagHaminhaYalkutYosef()` היא מילה במילה הנוסחה שלנו:

```js
plagHaminchaCore(time) { return time.subtract(this.fixedToSeasonal(Duration.from({hours:1, minutes:15}))); }
fixedToSeasonal(portion, fullDay = this.timeRange.current.ranges.gra)   // ranges.gra = sunrise.until(sunset)
getPlagHaminhaYalkutYosef() { return this.plagHaminchaCore(this.timeRange.current.nightfall); }
```

`nightfall` שם הוא שקיעה + 13.5 דקות זמניות — **ולא** `tzethakokhavim`
(16.04°/72 דקות) ולא `stringentNightfall` (20 דקות). כלומר: שעה זמנית של
הגר״א, נמדדת מצאת הגאונים. בדיוק שתי ההחלטות שהיו בספק.

**הנוסחאות החלופיות נשללו במספרים, לא בטיעון.** מול 25 הערכים המפורסמים של
הלוח, ברזולוציית שניות:

| הנוסחה | סטייה מהלוח |
|---|---|
| **צאת − 1¼ שעות גר״א** (שלנו) | **25/25 בתוך שנייה אחת** |
| צאת − 1¼ שעות מג״א | 0/25 — שוגה ב־445 עד 617 שניות |
| שקיעה − 1¼ שעות גר״א (השורה השנייה שלנו) | 0/25 — שוגה ב־675 עד 935 שניות |
| צאת − 1¼ שעות של יום נץ→צאת | 0/25 — שוגה ב־70 עד 98 שניות |

השורה האחרונה היא החשובה: זו ההצעה ה״עקבית״ שמבקר היה מציע, והיא נשללת
ברזולוציית שניות. הלוח באמת משתמש בשעה הפשוטה של נץ→שקיעה, ומודד אותה מהצאת.

**הלוח המודפס עצמו.** `maor.orhachaim.org` מפרסם לשבוע פרשת כי־תבוא פלג אחד
בלבד, בטווח **18:05–18:11** לירושלים/תל־אביב/חיפה/באר־שבע. אצלנו באותו יום
(23.8.2026): 18:07 / 18:09 / 18:08 / 18:08 — בתוך הטווח. השורה השנייה שלנו
(17:52–17:54) אינה בטווח, כלומר הפלג היחיד שהלוח מדפיס הוא **שורת הלוח שלנו**.

**מול Hebcal, ברמת הרגע ולא המחרוזת.** משיכה חדשה של כל 72 הערכים בדיוק של
שניות: הפרש מקסימלי **2 שניות**. כל ה״דקה״ הזו היא המחרוזת המודפסת בלבד.
יתרה מזו, ה־plag של Hebcal מקדים ב־0.5 שנייה את הזריחה/שקיעה של Hebcal עצמו,
בעוד השארית הפנימית שלנו היא ‎+0.036 שנייה — החישוב שלנו הדוק יותר משלו.

**מקורות נוספים שנבדקו ולא היו קודם:** MyZmanim (מנוע עצמאי, דיוק שניות) —
3 עד 16 שניות מאיתנו, וההפרש עוקב אחת לאחת אחרי מודל הגובה שלו ולא אחרי הפלג;
חזון שמים; thekotel.org; Chabad. אף אחד מהם לא הראה פער שאינו מוסבר בגובה,
בעיגול, או במחלוקת בין שתי השיטות.

### שאלה פתוחה — כיוון העיגול של הפלג

זו **החלטה שלך, לא באג**. היום אנחנו חותכים שניות בכל הזמנים. לזמני סוף זה
הכיוון הבטוח; לפלג — שהוא זמן התחלה — הכיוון הבטוח הפוך, והלוח עצמו מעגל את
שורות הפלג כלפי מעלה. מדובר בפחות מדקה, ורק בשתי שורות. אם תרצה, נעגל את שתי
שורות הפלג כלפי מעלה ונשאיר את כל השאר כפי שהוא.
